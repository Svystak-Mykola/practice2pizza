# 🍕 UrPizza — Order Management System

**UrPizza** — це автоматизована система управління замовленнями для піцерії (POS-система), розроблена на мові Java з використанням сучасних архітектурних підходів. Проєкт поєднує в собі потужну бізнес-логіку та зручний графічний інтерфейс для управління продажами та клієнтами.

## 🚀 Основні можливості


**Авторизація та профілі**: Надійна система реєстрації та входу користувачів.



**Інтерактивне меню**: Перегляд асортименту піц із фільтрацією за категоріями та вибором розмірів.



**Розумний кошик**: Управління обраними позиціями в реальному часі перед оформленням замовлення.



**Обробка замовлень**: Повний цикл створення та збереження замовлень у базі даних.



**Автоматичні міграції**: Використання Flyway для автоматичного розгортання структури БД та початкових даних.



## 🏗 Архітектура проєкту

Архітектура програмного продукту побудована на основі багаторівневого підходу з використанням принципів **Clean Architecture** та окремих концепцій **Domain-Driven Design (DDD)**. Систему логічно поділено на такі рівні:


**Presentation**: Графічний інтерфейс на JavaFX (контролери та FXML).



**Application**: Рівень прикладних сервісів та контрактів, що координують роботу бізнес-логіки.



**Domain**: Ядро системи, що містить основні сутності та правила бізнесу.



**Infrastructure**: Реалізація репозиторіїв, робота з PostgreSQL.



Усі компоненти реалізовані відповідно до принципів **SOLID**, зокрема принципу єдиної відповідальності (SRP) та принципу інверсії залежностей (DIP).

## 🛠 Технологічний стек


**Language**: Java 21



**GUI Framework**: JavaFX


**Database**: PostgreSQL


**Build Tool**: Maven


**DB Migration**: Flyway

**Installer**: jpackage (MSI)



## 📦 Встановлення та запуск

### Використання інсталятора

1. Перейдіть у розділ репозиторію [Releases](https://www.google.com/search?q=https://github.com/Svystak-Mykola/practice2pizza/releases).
2. Завантажте файл `UrPizza-1.0.0.msi`.


3. Встановіть програму як звичайний Windows-застосунок.



### Збірка з вихідного коду

Для самостійної збірки знадобиться JDK 21 та Maven:

```bash
git clone https://github.com/Svystak-Mykola/practice2pizza.git
cd practice2pizza
mvn clean package

```

## 📂 Структура директорій

```text
src/main/java/pizzeria/
├── application/     # Сервіси та інтерфейси логіки
├── domain/          # Сутності (User, Pizza, Order)
├── infrastructure/  # Робота з БД та репозиторії
├── presentation/    # Контролери JavaFX
└── util/            # Допоміжні класи (ConnectionPool тощо)

```
